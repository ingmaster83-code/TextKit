보이지 않는 문자 탐지 · 제거기

복사한 텍스트에 섞인 제로폭 공백(U+200B), NBSP, 전각 공백, 소프트 하이픈, 방향 덮어쓰기(Trojan Source), 한글 필러(U+3164), 점자 공백, 태그 문자, 제어 문자를 찾아 줄:열 위치와 위험도를 표로 보여 주고 [U+XXXX] 로 표시하거나 한 번에 제거합니다.

사용 예시

⚠️ 의심 문자 10개 (10종류)

Hello​World, price is 100　won.
user‮admin‬ = "ok";­ soft⁠ joined‍ text﻿ㅤ

이 도구로 할 수 있는 일

복사·붙여넣기 후 이유 없이 동작하지 않는 텍스트의 원인을 찾습니다. 텍스트는 서버로 전송되지 않습니다.

  • 탐지: 제로폭 문자(200B·200C·200D·2060·FEFF), 특수 공백(NBSP·전각·얇은 공백), 소프트 하이픈, 방향 제어(LRM·RLM·LRO·RLO·격리), 한글 필러(3164 등), 점자 공백, 태그 문자, 제어 문자, 대체 문자(�)
  • 표: 줄:열, 코드, 이름, 분류, 위험도(낮음~심각), 앞뒤 문맥과 종류별 개수
  • 정리: 모두 제거(공백류는 일반 공백으로), 공백류만 변환, 제거 없이 [U+XXXX] 표시
  • 이모지 시퀀스의 ZWJ·변형 선택자는 정상으로 간주하는 옵션, 맨 앞 BOM 제외 옵션

💡 Tips

  • 비밀번호·API 키·URL 을 붙여 넣었는데 실패하면 제로폭 공백이 끼어 있는지 확인하세요.
  • 소스 코드나 파일 이름의 방향 제어 문자는 겉모양과 실제 내용이 다르게 보이게 만들 수 있어 위험합니다.
  • 한글 필러(ㅤ)는 빈 이름처럼 보이지만 공백 검사를 통과합니다. 닉네임 검증에 이 탐지를 추가하세요.

자주 묻는 질문

ZWJ 를 모두 지우면 이모지가 깨지나요?

네. 👨‍👩‍👧 같은 결합 이모지는 ZWJ 로 이어져 있어 지우면 따로 분리됩니다. 그래서 이모지 옆의 ZWJ 는 기본으로 정상 처리합니다.

한글 텍스트의 정상적인 공백도 지우나요?

아니요. 일반 공백(U+0020), 탭, 줄바꿈은 건드리지 않고 특수 공백만 대상으로 합니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
