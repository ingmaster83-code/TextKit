이 도구로 할 수 있는 일

깨진 문자열의 원래 모양을 추측해 복원합니다. 텍스트는 서버로 전송되지 않습니다.

  • 모지바케: UTF-8 을 Latin-1(CP1252)로 잘못 읽음, 이중 인코딩, UTF-8 을 EUC-KR·Shift_JIS·GBK·Big5·EUC-JP 로 잘못 읽음, 그 문자 집합의 바이트를 Latin-1 로 읽음
  • 디코딩: 퍼센트 인코딩(URL), HTML 엔티티(&#xC548;), \uC548·\xE9 이스케이프, MIME 인코딩 단어(=?UTF-8?B?…?=), Quoted-Printable
  • 점수: 대체 문자(�), 제어 문자, 모지바케 특유의 글자 패턴, 한글·라틴 혼합 단어 등을 보고 후보 순위를 매김
  • 여러 줄을 한 번에 처리하고 줄마다 가장 좋은 결과를 모아 출력

자주 묻는 질문

항상 완전히 복구되나요?

바이트가 그대로 남아 있을 때만 복구됩니다. 일부 글자가 '?' 나 '�' 로 바뀐 텍스트는 그 부분을 되살릴 수 없습니다.

EUC-KR 과 CP949 는 같은가요?

브라우저의 euc-kr 은 CP949(확장 완성형)로 동작해 대부분의 한글 음절을 지원합니다. 이 도구도 같은 규칙을 사용합니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
