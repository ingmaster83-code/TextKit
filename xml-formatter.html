자주 묻는 질문
XML 유효성 검사가 되나요?
네, DOMParser를 이용해 XML 형식 오류를 감지하고 오류 위치를 표시합니다.
JSON 포맷터와 차이가 뭔가요?
XML 포맷터는 XML 전용으로 태그, 속성, CDATA 등 XML 문법에 맞게 정렬합니다.
큰 XML 파일도 처리할 수 있나요?
브라우저 메모리 내에서 처리되므로 일반적인 크기의 XML은 빠르게 처리됩니다.
파일이 서버에 저장되나요?
아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 완전히 안전합니다.
