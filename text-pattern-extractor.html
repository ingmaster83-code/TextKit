텍스트 패턴 추출기 (이메일 · URL · 전화번호 · IP)

로그, 메일 본문, 문서에서 이메일, URL, 전화번호, IPv4·IPv6, 날짜, 금액, 해시태그, 멘션, 색상 코드, UUID 같은 값만 뽑아 줍니다. 중복 제거와 정렬, 등장 위치(줄:열), 유형별 개수 요약을 제공하고 직접 정규식을 넣어 추출할 수도 있습니다. 주민등록번호·카드번호 형식은 개인정보 경고와 함께 알려 줍니다.

사용 예시

✅ 16개 찾음 (고유 16개)

입력 — 텍스트

문의: help@wooahouse.com, sales@example.co.kr / 전화 02-1234-5678, 010-9876-5432
서버 192.168.0.10 (백업 10.0.0.255) 접속 https://wooahouse.com/docs?id=7, http://example.org/a.

이 도구로 할 수 있는 일

긴 텍스트 안에서 필요한 값만 골라냅니다. 텍스트는 서버로 전송되지 않습니다.

  • 항목: 이메일, URL, 한국·국제 전화번호, IPv4, IPv6, 날짜(ISO·한글), 금액(원), 숫자, 해시태그, @멘션, 16진수 색상, UUID, 한글·영어 단어
  • 개인정보 점검: 주민등록번호 형식, Luhn 검사를 통과한 카드번호 형식을 찾아 경고
  • 정리: 중복 제거, 등장 순서·가나다순·빈도순 정렬, 값별 횟수와 처음 위치(줄:열)
  • 직접 정규식: i m s u 플래그, 잘못된 정규식 오류 안내
  • 모두 보기: 유형별 전체·고유 개수 요약 표와 한 줄에 하나씩 복사용 목록

💡 Tips

  • URL 뒤에 붙은 마침표·쉼표·괄호는 자동으로 제외합니다. 필요하면 직접 정규식을 쓰세요.
  • 로그에서 IP 만 모아 빈도순으로 정렬하면 접속이 많은 주소를 바로 볼 수 있습니다.
  • 추출한 목록은 '줄 정렬·중복 제거'에 붙여 넣어 추가로 정리할 수 있습니다.

자주 묻는 질문

전화번호·이메일을 정확히 검증하나요?

형식만 보고 찾습니다. 실제 사용 중인 번호나 주소인지는 확인하지 않으며 드물게 비슷한 숫자열이 섞일 수 있습니다.

정규식 문법은 무엇인가요?

브라우저의 JavaScript 정규식입니다. 유니코드 속성(\p{L} 등)을 쓰려면 u 플래그를 켜세요.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
