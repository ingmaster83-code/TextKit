유니코드 검사기 (코드 포인트 · 문자소)

텍스트의 모든 문자를 코드 포인트(U+XXXX), 이름, 일반 분류, 스크립트, UTF-8·UTF-16 바이트로 풀어 보여 주고 문자소(화면에서 보이는 글자) 수와 length 의 차이를 설명합니다. 한글 음절 이름, 이모지 ZWJ 시퀀스, 결합 문자, 제로폭 문자를 한눈에 확인할 수 있습니다.

사용 예시

✅ 코드 포인트 30개 · 문자소 25개 · UTF-8 57바이트

Hello, 안녕! café 👨‍👩‍👧 한글​ Á ①

이 도구로 할 수 있는 일

글자가 왜 이렇게 세어지는지, 보이지 않는 문자가 있는지 확인합니다. 텍스트는 서버로 전송되지 않습니다.

  • 문자별 표: 코드 포인트, 이름(한글 음절·CJK 포함), 일반 분류(Lu, Ll, Mn, Cf 등), 스크립트, UTF-8 바이트, UTF-16 코드 유닛
  • 요약: 코드 포인트·문자소·UTF-16·UTF-8 개수, 이미 정규화된 형식, 스크립트 구성
  • 문자소 표: 여러 코드 포인트로 이루어진 글자(가족 이모지, é 의 결합형 등)
  • 점검: 제로폭·방향 제어 문자, 분해된 한글 자모(NFD), JS length 와 실제 글자 수의 차이

💡 Tips

  • 이모지 한 개가 length 2~11 이 되는 이유를 코드 포인트 표에서 확인하세요.
  • 한글이 분해형(NFD)이면 검색·정렬이 달라집니다. '유니코드 정규화' 도구로 NFC 로 합치세요.
  • 복사한 텍스트가 이상하게 동작하면 제어·제로폭 문자가 섞였는지 먼저 보세요.

자주 묻는 질문

모든 문자의 이름이 나오나요?

자주 쓰는 문자, 한글 음절, CJK 한자는 이름을 보여 주고 나머지는 분류와 스크립트 중심으로 보여 줍니다.

코드 포인트와 문자소의 차이는 무엇인가요?

코드 포인트는 유니코드 번호 하나이고 문자소는 사람이 한 글자로 느끼는 단위입니다. é(e+결합 악센트)나 👨‍👩‍👧 는 여러 코드 포인트가 한 문자소입니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
