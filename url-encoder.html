💡 Tips

  • URL에 포함된 한글·특수문자를 %XX 형식으로 인코딩합니다.
  • query string에 사용하려면 전체 URL이 아닌 값 부분만 인코딩하세요.
  • 디코딩으로 %XX 형식의 URL을 사람이 읽기 쉽게 변환할 수 있습니다.

자주 묻는 질문

URL 인코딩이 왜 필요한가요?

URL에 한글, 특수문자가 포함될 때 브라우저가 올바르게 처리할 수 있도록 %xx 형식으로 변환합니다.

인코딩과 디코딩 모두 가능한가요?

네, URL 인코딩과 디코딩 양방향 모두 지원합니다.

전체 URL과 파라미터 값 중 어떤 걸 인코딩해야 하나요?

일반적으로 URL의 파라미터 값 부분만 인코딩하는 것이 좋습니다.

파일이 서버에 저장되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 완전히 안전합니다.
