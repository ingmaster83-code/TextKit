자주 묻는 질문

정규식 모드는 어떻게 사용하나요?

각 규칙의 .* 버튼을 눌러 활성화하면 찾기 필드에 정규식 패턴을 입력할 수 있습니다. 예: \d+는 숫자를, \s+는 공백을 매칭합니다.

여러 단어를 한번에 바꿀 수 있나요?

네, + 규칙 추가 버튼으로 규칙을 여러 개 추가하면 순서대로 모두 적용됩니다. 규칙은 위에서 아래 순으로 실행됩니다.

원본 텍스트는 변경되나요?

아니요, 원본은 그대로 유지되고 결과 영역에 치환된 텍스트가 표시됩니다. 원본 영역의 내용을 직접 수정하기 전까지 보존됩니다.

대소문자 무시 옵션은 무엇인가요?

각 규칙의 Aa 버튼을 활성화하면 대소문자를 구분하지 않고 치환합니다. 예: "Hello"를 찾으면 "hello", "HELLO"도 함께 치환됩니다.

바꾸기 필드를 비워두면 어떻게 되나요?

찾은 텍스트가 빈 문자열로 치환됩니다. 즉, 해당 패턴과 일치하는 텍스트를 모두 삭제하는 효과를 얻을 수 있습니다.
