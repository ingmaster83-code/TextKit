동형 이의(Homoglyph) 문자 탐지기

paypal.com 처럼 보이지만 일부가 키릴 문자인 도메인, 'аdmin' 같은 위장 계정, 전각 문자 등 겉모양이 비슷한 문자를 찾아 줍니다. 한 단어 안의 스크립트 혼용을 검사하고 ASCII 로 환원한 스켈레톤과 punycode 를 보여 주며, 두 문자열이 겉모양이 같은지 비교할 수도 있습니다.

이 도구로 할 수 있는 일

도메인, 사용자 이름, 코드에 닮은꼴 문자가 섞였는지 확인합니다. 텍스트는 서버로 전송되지 않습니다.

  • 탐지: 키릴·그리스 대문자·소문자, 전각 ASCII, 수학/원문자 서식 문자, 한글 자모와 한자(ㅇ ㅡ ㅣ 一 〇)가 ASCII 와 닮은 경우
  • 스크립트 혼용: 한 단어에서 라틴+키릴처럼 섞인 경우를 경고(한·중·일 정상 조합은 허용)
  • 스켈레톤: 닮은 문자를 ASCII 로 환원한 값과 도메인 형태 단어의 punycode(xn--)
  • 비교: 텍스트 B 와 스켈레톤이 같으면 스푸핑 가능성을 알림, l/I/1·O/0 처럼 글꼴에 따라 헷갈리는 ASCII 도 표시

💡 Tips

  • 브라우저가 주소창에 xn-- 로 표시하는 도메인은 대개 스크립트가 섞였다는 뜻입니다. 클릭하기 전에 확인하세요.
  • 사용자 이름 중복 검사는 원문 비교가 아니라 NFKC 정규화 + 스켈레톤 비교로 해야 위장 계정을 막습니다.
  • 소스 코드 리뷰에서는 변수명에 섞인 키릴 문자가 컴파일은 되지만 의도와 다르게 동작하는 원인이 되기도 합니다.

자주 묻는 질문

모든 닮은꼴 문자를 찾나요?

자주 악용되는 문자 위주의 부분집합입니다. 유니코드 컨퓨저블 전체 데이터는 포함하지 않으므로 중요한 판단에는 punycode 도 함께 확인하세요.

한글 텍스트도 문제로 표시되나요?

한글만 있거나 한글과 영문, 한자가 섞인 정상적인 조합은 경고하지 않습니다. 한글 자모 중 ASCII 와 닮은 글자만 참고용으로 표시합니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
