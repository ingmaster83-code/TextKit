ICU MessageFormat 테스터

번역 파일에 쓰는 ICU 메시지를 입력하고 JSON 인자 값을 넣으면 선택한 로케일에서 실제로 어떻게 출력되는지 보여 줍니다. plural(offset 포함), selectordinal, select, number(스켈레톤), date·time, 중첩과 따옴표 이스케이프를 지원하고 other 누락, 로케일에 맞지 않는 복수형 범주, 인자 누락을 알려 줍니다.

사용 예시

✅ 서식 성공 (ko-KR)

입력 — ICU 메시지 (MessageFormat)

{gender, select, female{그녀는} male{그는} other{그들은}} 사진 {count, plural, =0{없음} =1{한 장을} other{# 장을}} 올렸습니다. 총액 {price, number, ::currency/KRW}, {when, date, long}

입력 — 인자 값 (JSON 객체)

{"gender":"female","count":3,"price":12500,"when":"2026-10-17T09:00:00Z"}

결과 — 서식 결과

그녀는 사진 3 장을 올렸습니다. 총액 ₩12,500, 2026년 10월 17일

결과 — 인자

인자 | 종류 | 입력 값 | 상태
gender | select | "female" | ✅
count | plural | 3 | ✅
price | number | 12500 | ✅
when | date | "2026-10-17T09:00:00Z" | ✅

이 도구로 할 수 있는 일

번역 메시지를 앱에 넣기 전에 문법과 출력을 확인합니다. 메시지와 인자는 서버로 전송되지 않습니다.

  • 문법: {name}, {n, number[, integer|percent|currency|::스켈레톤]}, {d, date|time[, short|medium|long|full|::스켈레톤]}, plural/selectordinal(offset, =N, #), select, 중첩
  • 따옴표 규칙: '' → ', '{' 로 중괄호 이스케이프, plural 안의 '#'
  • 점검: other 누락, 알 수 없는 범주, 로케일이 쓰지 않는 범주(예: ko 의 one), 필요한 범주 누락, 숫자·날짜 값 오류, 인자 누락·미사용
  • 결과: 서식된 메시지, 인자 표(종류·값), 구문 트리(JSON), 로케일의 plural 범주 안내
  • 로케일·시간대 설정으로 en-US, ru, ar-EG 등 결과 비교

💡 Tips

  • 러시아어·폴란드어·아랍어는 one 외에 few, many 등이 필요합니다. 로케일을 바꿔 가며 확인하세요.
  • 한국어·일본어·중국어는 other 하나만 쓰지만 =0, =1 같은 정확한 값 옵션은 쓸 수 있습니다.
  • 번역가에게는 plural 안의 문장을 통째로 쓰게 하고 숫자는 # 로 표시하게 하세요.

자주 묻는 질문

formatjs·ICU4J 와 결과가 같은가요?

ICU MessageFormat 문법을 따르지만 브라우저의 Intl 로 서식하므로 일부 서식 세부(예: 날짜 스켈레톤 패턴)는 라이브러리와 다를 수 있습니다.

태그(<b>…</b>)나 rich text 도 되나요?

지원하지 않습니다. 순수 ICU 메시지 문법만 해석합니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
