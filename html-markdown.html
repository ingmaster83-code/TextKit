자주 묻는 질문

Q. 어떤 HTML 태그를 지원하나요?

h1~h6 제목, p 단락, ul/ol/li 목록, a 링크, strong/em 강조, code 인라인 코드, pre/code 코드 블록, blockquote 인용, table 표, img 이미지 등 주요 HTML 태그를 마크다운으로 변환합니다.

Q. 텍스트가 서버로 전송되나요?

아니요, 모든 변환은 브라우저 내에서만 처리됩니다. 입력한 텍스트는 외부로 전송되지 않습니다.

Q. 마크다운 → HTML 변환도 되나요?

네, 마크다운을 HTML로 변환하면 실제 HTML 코드가 생성됩니다. 블로그 포스팅이나 웹 페이지에 바로 사용할 수 있습니다.
