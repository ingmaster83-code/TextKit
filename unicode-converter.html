💡 Tips

  • 텍스트를 \uXXXX, &#XXXX;, U+XXXX 등 다양한 Unicode 표기로 변환합니다.
  • 이모지나 특수문자의 코드 포인트를 확인할 때 유용합니다.
  • 프로그래밍 언어의 문자열 이스케이프 처리에 활용하세요.

자주 묻는 질문

유니코드 이스케이프는 어디에 쓰이나요?

JavaScript 소스코드, JSON 파일, URL 인코딩 등에서 ASCII가 아닌 문자를 안전하게 표현할 때 사용합니다.

한글도 변환되나요?

네, 한글·이모지·특수문자 등 모든 유니코드 문자를 변환할 수 있습니다.

이모지처럼 4바이트 문자는 어떻게 표현되나요?

U+10000 이상의 문자는 \u{XXXXX} 형식(ES6 이후)으로 표현됩니다.

파일이 서버에 저장되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 완전히 안전합니다.
