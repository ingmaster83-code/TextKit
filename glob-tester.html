Glob · .gitignore 패턴 테스터

패턴과 경로 목록을 넣으면 어떤 경로가 일치하는지, 어떤 규칙이 결정했는지 표로 보여 줍니다. minimatch 방식의 glob(**, *, ?, 중괄호, 문자 집합, ! 제외)과 .gitignore 방식(마지막 규칙 우선, 폴더 전용 슬래시, 루트 고정)을 모두 지원하고 각 패턴을 정규식으로 바꾼 결과도 보여 줍니다.

사용 예시

✅ 9개 중 4개 일치

입력 — 패턴 (한 줄에 하나, # 주석, ! 로 시작하면 제외)

src/**/*.{js,ts}
!**/*.test.*
*.md
# 숨김 파일은 기본적으로 제외됩니다
**/node_modules/**

입력 — 경로 목록 (한 줄에 하나)

src/index.js
src/utils/format.ts
src/utils/format.test.ts
src/.hidden/config.js
README.md
docs/guide.md
node_modules/lib/index.js
package.json
lib/a/b/c.js

결과 — 경로별 결과

경로 | 결과 | 결정한 규칙
src/index.js | ✅ 일치 | src/**/*.{js,ts}
src/utils/format.ts | ✅ 일치 | src/**/*.{js,ts}
src/utils/format.test.ts | — 불일치 | !**/*.test.*
src/.hidden/config.js | — 불일치 | —
README.md | ✅ 일치 | *.md
docs/guide.md | — 불일치 | —
node_modules/lib/index.js | ✅ 일치 | **/node_modules/**
package.json | — 불일치 | —
lib/a/b/c.js | — 불일치 | —

결과 — 패턴 → 정규식

패턴 | 정규식
src/**/*.{js,ts} | ^src\/(?:(?:(?!\.)[^/]*)/)*(?!\.)[^/]*\.js$
src/**/*.{js,ts} | ^src\/(?:(?:(?!\.)[^/]*)/)*(?!\.)[^/]*\.ts$
!**/*.test.* | ^(?:(?:(?!\.)[^/]*)/)*(?!\.)[^/]*\.test\.[^/]*$
*.md | ^(?!\.)[^/]*\.md$
**/node_modules/** | ^(?:(?:(?!\.)[^/]*)/)*node_modules\/.*$

이 도구로 할 수 있는 일

빌드 설정이나 .gitignore 를 고치기 전에 패턴이 의도대로 동작하는지 확인합니다. 입력은 서버로 전송되지 않습니다.

  • glob: *, **, ?, [abc]·[!abc]·[a-z], {js,ts}, {1..3}, 앞의 ! 로 제외, # 주석, 점 파일 옵션, 대소문자 옵션
  • .gitignore: 슬래시 없는 이름은 모든 깊이에서 일치, 앞의 / 는 루트 기준, 끝의 / 는 폴더만, 마지막으로 일치한 규칙이 우선, 상위 폴더가 무시되면 ! 로 되살릴 수 없음
  • 결과: 경로별 일치 여부와 결정한 규칙, 일치한 경로만 복사
  • 패턴 → 정규식 변환 표로 동작 원리 확인

함께 쓰면 좋은 도구

🔍정규식 테스터 📋줄 정렬·중복 제거 🔄텍스트 치환기 🔍텍스트 비교

💡 Tips

  • * 는 / 를 넘지 못합니다. 여러 폴더를 포함하려면 ** 를 쓰세요.
  • .gitignore 에서 build 는 어느 깊이의 build 든 무시하지만 /build 는 루트의 build 만 무시합니다.
  • 폴더가 무시되면 그 안의 파일은 ! 로 다시 포함할 수 없습니다. 폴더 대신 내용물 패턴(build/*)을 쓰세요.

자주 묻는 질문

extglob(@(a|b))도 되나요?

지원하지 않습니다. {a,b} 중괄호나 여러 줄 패턴으로 바꿔 쓰세요.

Git 과 결과가 다를 수 있나요?

핵심 규칙은 구현했지만 모든 예외(예: 이미 추적 중인 파일, 전역 ignore)는 다루지 않습니다. 최종 확인은 git check-ignore -v 로 하세요.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
