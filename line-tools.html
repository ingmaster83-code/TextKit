자주 묻는 질문

어떤 기능을 제공하나요?

줄 정렬(알파벳/가나다순), 중복 줄 제거, 빈 줄 제거, 줄 뒤집기 기능을 제공합니다.

대용량 텍스트도 처리 가능한가요?

브라우저 메모리 내에서 처리되므로 일반적인 텍스트는 빠르게 처리됩니다.

처리 결과를 바로 복사할 수 있나요?

네, 처리 결과를 원클릭으로 복사할 수 있습니다.

파일이 서버에 저장되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 완전히 안전합니다.
