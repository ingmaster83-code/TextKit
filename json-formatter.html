💡 Tips
  • 들여쓰기 2칸 또는 4칸으로 JSON을 보기 좋게 포맷합니다.
  • 압축(minify) 기능으로 JSON을 한 줄로 만들어 전송 크기를 줄이세요.
  • 유효하지 않은 JSON이면 오류 위치를 표시해줍니다.


자주 묻는 질문
JSON 유효성 검사도 되나요?
네, JSON 형식 오류가 있으면 오류 위치를 표시하여 수정을 도와줍니다.
압축(minify) 기능도 있나요?
네, 들여쓰기 정렬(pretty) 외에도 공백을 제거하는 압축 기능을 제공합니다.
큰 JSON 파일도 처리 가능한가요?
브라우저 메모리 내에서 처리되므로 일반적인 크기의 JSON은 빠르게 처리됩니다.
파일이 서버에 저장되나요?
아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 완전히 안전합니다.
