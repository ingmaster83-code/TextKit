슬러그 생성기 — URL Slug 변환

텍스트를 URL에 사용할 수 있는 슬러그로 변환합니다. 한글 음역, 구분자·대소문자 옵션을 지원합니다.

구분자

💡 Tips

  • 제목을 URL 친화적인 slug로 자동 변환합니다.
  • 공백은 하이픈(-)으로, 특수문자는 제거됩니다.
  • SEO 최적화된 URL을 만들 때 활용하세요.

자주 묻는 질문

슬러그(slug)가 뭔가요?

URL에서 사용할 수 있는 소문자·하이픈으로 구성된 짧은 문자열입니다. 예: hello-world.

한글 슬러그도 만들 수 있나요?

한글을 영문으로 음역(romanization)하거나 한글 그대로 슬러그를 만들 수 있습니다.

어떤 경우에 슬러그를 사용하나요?

블로그 포스트 URL, 제품 URL, API 경로 등 사람이 읽기 쉬운 URL을 만들 때 사용합니다.

파일이 서버에 저장되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 완전히 안전합니다.
