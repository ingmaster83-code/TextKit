Unicode Inspector (Code Points & Graphemes)

Expand every character of a text into its code point (U+XXXX), name, general category, script and UTF-8 / UTF-16 bytes, and see how the number of graphemes (user-perceived characters) differs from length. Hangul syllable names, emoji ZWJ sequences, combining marks and zero-width characters are easy to spot.

What this tool does

Find out why text is counted the way it is and whether invisible characters are hiding in it. Your text is not uploaded.

  • Per-character table: code point, name (including Hangul syllables and CJK), general category (Lu, Ll, Mn, Cf ...), script, UTF-8 bytes and UTF-16 code units
  • Summary: counts of code points, graphemes, UTF-16 units and UTF-8 bytes, already-normalised forms and script mix
  • Grapheme table: characters made of several code points (family emoji, decomposed é ...)
  • Checks: zero-width and bidi controls, decomposed Hangul jamo (NFD) and the gap between JS length and real character count

Frequently Asked Questions

Is every character's name shown?

Names are given for common characters, Hangul syllables and CJK ideographs; others show category and script.

What is the difference between a code point and a grapheme?

A code point is one Unicode number; a grapheme is what a person sees as one character. é (e + combining accent) or 👨‍👩‍👧 are several code points forming one grapheme.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
