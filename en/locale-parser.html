Preview that locale's date, number, currency, list and relative-time formatting and its plural categories too.

What this tool does

Check that your locale tags are correct when building multilingual apps. Tags are not uploaded.

  • Parsing: language, script, region and Unicode extensions (calendar ca, numbering system nu, hour cycle hc, collation co)
  • Cleanup: canonical casing, notes for POSIX-style tags (de_CH), maximized / minimized forms and validity
  • Names: language, script and region names in Korean, English, Japanese or Chinese
  • Preview: full and short dates, numbers, currency, percent, lists, relative time, hour cycle and first weekday
  • Plural categories: cardinal and ordinal categories (needed for ICU plural messages)

💡 Tips

  • BCP 47 uses hyphens; an underscore form such as en_US is POSIX / Java style, so write en-US.
  • ko has a single plural category (other) while Russian and Arabic need 3 to 6.
  • Distinguish Simplified and Traditional Chinese by script (zh-Hans / zh-Hant) rather than by region.

Frequently Asked Questions

Do results differ between browsers?

Intl data (CLDR) versions and supported locales differ, so samples and names can vary slightly.

What about unsupported locales?

A valid tag without data in the browser is marked 'no data in this browser' and the samples fall back to the default locale.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
