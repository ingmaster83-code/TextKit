ICU MessageFormat Tester

Enter an ICU message from your translation files plus JSON argument values and see exactly how it renders in the chosen locale. Supports plural (with offset), selectordinal, select, number (skeletons), date and time, nesting and apostrophe escaping, and reports a missing other, plural categories the locale does not use, and missing arguments.

Example

✅ Formatted (ko-KR)

Input — ICU message (MessageFormat)

{gender, select, female{그녀는} male{그는} other{그들은}} 사진 {count, plural, =0{없음} =1{한 장을} other{# 장을}} 올렸습니다. 총액 {price, number, ::currency/KRW}, {when, date, long}

Input — Argument values (JSON object)

{"gender":"female","count":3,"price":12500,"when":"2026-10-17T09:00:00Z"}

Result — Formatted result

그녀는 사진 3 장을 올렸습니다. 총액 ₩12,500, 2026년 10월 17일

Result — Arguments

Argument | Type | Value | Status
gender | select | "female" | ✅
count | plural | 3 | ✅
price | number | 12500 | ✅
when | date | "2026-10-17T09:00:00Z" | ✅

What this tool does

Check the syntax and output of translation messages before shipping them. Messages and arguments are not uploaded.

  • Syntax: {name}, {n, number[, integer|percent|currency|::skeleton]}, {d, date|time[, short|medium|long|full|::skeleton]}, plural / selectordinal (offset, =N, #), select and nesting
  • Quoting: '' → ', '{' escapes braces, '#' inside plurals
  • Checks: missing other, unknown categories, categories the locale does not use (e.g. one in ko), required categories missing, bad number / date values, missing and unused arguments
  • Output: the formatted message, an argument table (type, value), the AST as JSON and the locale's plural categories
  • Locale and time-zone settings to compare en-US, ru, ar-EG and more

💡 Tips

  • Russian, Polish and Arabic need few, many and more besides one; switch locales to verify.
  • Korean, Japanese and Chinese use only other, but exact =0 / =1 options still work.
  • Ask translators to write the whole sentence inside each plural option and mark the number with #.

Frequently Asked Questions

Is the result identical to formatjs or ICU4J?

It follows ICU MessageFormat syntax but formats with the browser's Intl, so some details (such as date skeleton patterns) can differ from a library.

Are tags (<b>...</b>) or rich text supported?

No. Only plain ICU message syntax is parsed.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
