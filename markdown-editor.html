자주 묻는 질문

작성한 마크다운을 HTML로 내보낼 수 있나요?

네, 변환된 HTML 코드를 복사하거나 HTML 파일로 다운로드할 수 있습니다.

마크다운 문법을 몰라도 사용할 수 있나요?

툴바의 버튼을 사용하면 문법을 몰라도 쉽게 서식을 적용할 수 있습니다.

작성 내용이 자동 저장되나요?

브라우저 내에서만 처리되므로 페이지를 떠나면 내용이 저장되지 않습니다. 필요시 다운로드하여 저장하세요.

파일이 서버에 저장되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 완전히 안전합니다.
